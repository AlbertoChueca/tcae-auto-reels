# Cuaderno de viralidad (2026-10-29)

- Seguir haciendo: Ganchos de reto directo y específico como «¿Aciertas las 3?», que disparan los comentarios hasta 7.
- Dejar de hacer: Ganchos desgastados como «¿Te la sabes?». Datos insuficientes: solo 1 compartido en todo el historial para validar patrones virales.
- Probar: Reto entre compañeras: «Compártelo con tu compi de planta; si no acierta las 3, le toca el próximo timbre».
